Семантика (както се очаква на изпита):
- s.wait(): намалява s.cnt; ако след намаляването cnt < 0, процесът блокира
  и влиза в опашката s.L
- s.signal(): увеличава s.cnt; ако ПРЕДИ увеличаването cnt < 0, събужда
  един процес от s.L
- силен семафор = FIFO събуждане; слаб = произволен ред (starvation риск)
- инициализацията се прави от родителя, преди да тръгнат копията

Двете хватки, покриващи почти всичко:
1. TURNSTILE (въртележка): gate.wait(); gate.signal() — неизвестен брой
   чакащи минават каскадно след едно-единствено gate.signal()
2. БРОЯЧ ПОД MUTEX: m.wait(); cnt++; if (cnt == ГРАНИЦА) <отвори>; m.signal()

Правило: mutex-ът пази САМО брояча/флага, никога самите инструкции.
Трите въпроса, по които късат точки: може ли някой да блокира завинаги?
могат ли две тела да се препокрият? има ли излишно чакане?

ЗАДАЧА 0 (реалната от 13.06.2026, 10 т.) — първото копие специално
------------------------------------------------------------------------
Копия на процес P изпълняват p_1, p_2, p_3. Първото копие изпълнява
всичко; останалите НЕ изпълняват p_1, но чакат тя да приключи в първото,
после изпълняват p_2, p_3. Пълни точки: паралелизъм + без излишни
изчаквания след p_1 на първото.

РЕШЕНИЕ:
    Инициализация: Semaphore mutex(1), Semaphore gate(0), first = true

    process P:
        az_sam_parvi = false
        mutex.wait()
        if (first) { first = false; az_sam_parvi = true }
        mutex.signal()

        if (az_sam_parvi) {
            p_1
            gate.signal()            // отваря въртележката
        } else {
            gate.wait()              // чакам p_1 на първото копие
            gate.signal()            // каскада: пускам следващия
        }
        p_2
        p_3

Защо: броят копия N е неизвестен, затова не може N пъти signal — turnstile
каскадата пуска всички. Само едно gate.signal() без каскадата = 0 точки
(N-2 копия висят завинаги).

АЛТЕРНАТИВНО РЕШЕНИЕ (mutex + count + turnstile, само ЕДИН if — по-кратко):

    Инициализация: Semaphore mutex(1), Semaphore gate(0), cnt = 0

    process P:
        mutex.wait()
        cnt = cnt + 1
        if (cnt == 1) {          // само първият влязъл
            p_1
            gate.signal()
        }
        mutex.signal()
        gate.wait(); gate.signal() // turnstile
        p_2
        p_3

p_1 е вътре в mutex-а, но това НЕ е излишно чакане: останалите бездруго
нямат право на нищо, докато p_1 не свърши. Броячът замества флага first,
turnstile-ът замества else-клона.

ВАЖНО (ако питат на устно): съвсем БЕЗ if тази задача не се решава.
Всички копия изпълняват един и същ код; семафорите могат само да БАВЯТ
(wait), не да ПРЕСКАЧАТ инструкция. Ако p_1 е в кода без условие — всички
го изпълняват (чупи усл. 2); ако не е — никой (чупи усл. 1). Без if се
решават само чистите щафети/предшествания (напр. Зад. 3 either-or);
навсякъде с брояч с граница или "специално копие" трябва точно един if.

ЗАДАЧА 1в — МНОГОКРАТНА бариера: копията са в цикъл while(1){p_1; p_2}
и бариерата важи за всяка итерация поотделно
------------------------------------------------------------------------
РЕШЕНИЕ (двуфазна бариера):
    Инициализация: Semaphore mutex(1), Semaphore t1(0),
                   Semaphore t2(1), cnt = 0

    process P (в цикъл):
        p_1
        // фаза 1: събиране
        mutex.wait()
        cnt = cnt + 1
        if (cnt == N) { t2.wait(); t1.signal() }   // затвори изхода, отвори входа
        mutex.signal()
        t1.wait(); t1.signal()
        p_2
        // фаза 2: разпускане
        mutex.wait()
        cnt = cnt - 1
        if (cnt == 0) { t1.wait(); t2.signal() }   // затвори входа, отвори изхода
        mutex.signal()
        t2.wait(); t2.signal()

Защо две фази: с една бариера бързо копие обикаля цикъла и влиза в p_1 на
итерация i+1, докато бавните са още на p_2 от итерация i → броячът се чупи.

------------------------------------------------------------------------
РЕШЕНИЕ (щафета):
    Инициализация: Semaphore sp(1), Semaphore sq(0), cp = 0, cq = 0

    process P:                      process Q:
        sp.wait()                        sq.wait()
        p_1                             q_1
        cp = cp + 1                     cq = cq + 1
        if (cp < 3) sp.signal()          if (cq < 2) sq.signal()

ЗАДАЧА 5 — worker/query със снапшот (стилът на Зад.161/162 от сборника)
------------------------------------------------------------------------
worker: while(1){ process_all_requests }; query: make_request; read_result.
Между make_request и read_result — поне едно ПЪЛНО изпълнение, започнало
СЛЕД заявката. worker не блокира.

РЕШЕНИЕ:
    Инициализация: Semaphore mutex(1), Semaphore done(0), cnt = 0

    process query:                    process worker:
        make_request                      while (1) {
        mutex.wait()                           mutex.wait()
        cnt = cnt + 1                         k = cnt; cnt = 0      // снапшот
        mutex.signal()                         mutex.signal()
        done.wait()                            process_all_requests
        read_result                           for (i = 1; i <= k; i++)
                                                  done.signal()
                                          }

Снапшотът ПРЕДИ изпълнението гарантира: освобождават се само заявки,
влезли преди началото му → всяка е видяла едно пълно изпълнение.

ЗАДАЧА 6 — конкурентен ограничен стек (Зад.148, 2025-СИ) + бонус
------------------------------------------------------------------------
РЕШЕНИЕ (базово, 10 т.):
    Инициализация: Semaphore mutex(1), Semaphore free(N), Semaphore busy(0)

    push(x):              pop():                peek():
        free.wait()            busy.wait()            busy.wait()
        mutex.wait()           mutex.wait()           mutex.wait()
        <сложи x>             <махни връх>          v = <връх>
        mutex.signal()         mutex.signal()         mutex.signal()
        busy.signal()          free.signal()          busy.signal()   // връща!
                                                    return v

peek не консумира елемент → връща билета в busy. Редът free.wait() ПРЕДИ
mutex.wait() е задължителен (иначе deadlock: спиш на free с взет mutex).

БОНУС (паралелни peek, 20 т.) — мини readers-writers:
    Добави: Semaphore rmutex(1), readers = 0

    peek():
        busy.wait()
        rmutex.wait()
        readers = readers + 1
        if (readers == 1) mutex.wait()     // първият четец заключва писачите
        rmutex.signal()
        v = <връх>
        rmutex.wait()
        readers = readers - 1
        if (readers == 0) mutex.signal()   // последният отключва
        rmutex.signal()
        busy.signal()
        return v

ЗАДАЧА 0А (юни 2026, Зад.86) — make-movable.sh
------------------------------------------------------------------------
Връзки, сочещи ИЗВЪН директорията → абсолютни; сочещи ИЗ нея (вкл.
поддиректории) → релативни.

РЕШЕНИЕ:
    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <dir>" >&2; exit 1; }
    [ -d "$1" ] || { echo "$1 не е директория" >&2; exit 2; }

    root=$(realpath "$1")

    while IFS= read -r link; do
        target=$(readlink "$link")            # суровата цел
        linkdir=$(dirname "$link")

        if [ "${target#/}" != "$target" ]; then          # почва с / → абс.
            abs=$(realpath -m "$target")
        else                                             # рел. → спрямо dir-а на връзката
            abs=$(realpath -m "$linkdir/$target")
        fi

        case "$abs" in
            "$root"/*|"$root")                           # вътре → релативна
                new=$(realpath -m --relative-to="$linkdir" "$abs") ;;
            *)                                           # извън → абсолютна
                new="$abs" ;;
        esac
        ln -sfn "$new" "$link"
    done < <(find "$root" -type l)

Трите точки, на които се къса:
1. realpath -m — без -m счупена връзка гърми целия скрипт (set -e)
2. --relative-to="$linkdir" — релативно спрямо ДИРЕКТОРИЯТА НА ВРЪЗКАТА,
   не спрямо root
3. ln -sfn — без -n, ако старата връзка сочи към директория, новата се
   създава ВЪТРЕ в целта, вместо да замени връзката

ЗАДАЧА 0В (юни 2026, Зад.84) — orange-cat.sh (+ бонус 8 т.) [тествано]
------------------------------------------------------------------------
Рекурсивен !include препроцесор; пътищата са релативни спрямо директорията
на файла, СЪДЪРЖАЩ директивата. Бонус: при нечетим файл или цикъл — НИЩО
на stdout + грешка на stderr + неуспех.

РЕШЕНИЕ:
    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <file>" >&2; exit 1; }

    out=$(mktemp)
    trap 'rm -f "$out"' EXIT
    stack=""                              # "стек" от отворени файлове

    expand() {
        local file="$1" abs dir line
        [ -r "$file" ] || { echo "не може да се прочете: $file" >&2; exit 4; }
        abs=$(realpath "$file")           # ЗАДЪЛЖИТЕЛНО след -r проверката!
        case "$stack" in *"@${abs}@"*)
            echo "цикъл в include: $file" >&2; exit 3 ;;
        esac
        stack="${stack}@${abs}@"          # push
        dir=$(dirname "$abs")
        while IFS= read -r line || [ -n "$line" ]; do
            if [ "${line#\!include: }" != "$line" ]; then
                expand "$dir/${line#\!include: }"
            else
                printf '%s\n' "$line"
            fi
        done < "$abs"
        stack="${stack%@${abs}@}"         # pop
    }

    expand "$1" > "$out"                  # нищо на stdout преди успех
    cat "$out"

Проверено: вложени include-и (реле dir се сменя на всяко ниво), цикъл
(exit 3, празен stdout), нечетим файл (exit 4), повторен НЕцикличен
include е легален (цикъл = файлът е още "отворен" в стека).
Капан от тестването: realpath върху несъществуващ файл гърми — затова
проверката -r е ПРЕДИ realpath.

ЗАДАЧА 0Г (юни 2026, Зад.85) — runner.sh [тествано]
------------------------------------------------------------------------
Файл с опции: CMD <cmd>; ARGS ["а","б в",...]; ENV {"К":"С",...};
WORKDIR <дир>; # коментари; непознати опции се игнорират; последното
срещане печели; стойностите може да имат интервали, но не кавички.

РЕШЕНИЕ:
    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <optfile>" >&2; exit 1; }
    [ -f "$1" ] || { echo "$1 не е файл" >&2; exit 2; }

    cmd=""; workdir=""
    args=(); envs=()

    while IFS= read -r line || [ -n "$line" ]; do
        line="${line%%#*}"                        # коментара
        line="${line%"${line##*[![:space:]]}"}"   # trim отдясно
        [ -z "$line" ] && continue
        key="${line%% *}"
        val="${line#* }"
        case "$key" in
            CMD)     cmd="$val" ;;                 # последното печели
            WORKDIR) workdir="$val" ;;             # (просто презапис)
            ARGS)
                args=()
                while IFS= read -r item; do
                    args+=("$item")
                done < <(grep -oE '"[^"]*"' <<<"$val" | sed 's/^"//; s/"$//') ;;
            ENV)
                envs=()
                while IFS= read -r item; do
                    envs+=("$item")
                done < <(grep -oE '"[^"]*" *: *"[^"]*"' <<<"$val" \
                         | sed -E 's/^"([^"]*)" *: *"([^"]*)"$/\1=\2/') ;;
            *)       ;;                            # непозната → игнор
        esac
    done < "$1"

    [ -n "$cmd" ] || { echo "липсва CMD" >&2; exit 3; }
    [ -n "$workdir" ] && cd "$workdir"
    exec env ${envs[@]+"${envs[@]}"} "$cmd" ${args[@]+"${args[@]}"}

Проверено: "mmm, I like leaves" пристига като ЕДИН аргумент (само защото
args е МАСИВ, подаден с "${args[@]}" — string променлива = загуба на
точки); env K=V ... команда прилага променливите И търси командата с
новия PATH (затова примерът намира cowsay в /usr/games). На Linux
(bash>=4.4) може mapfile -t args < <(...) вместо while цикъла и просто
"${envs[@]}" на exec реда.

ВАРИАЦИЯ В1 — make-relative.sh: ВСИЧКИ връзки → релативни (и навън, с ../)
------------------------------------------------------------------------
РЕШЕНИЕ (като 0А, но без case — винаги релативна):
    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <dir>" >&2; exit 1; }
    [ -d "$1" ] || { echo "$1 не е директория" >&2; exit 2; }
    root=$(realpath "$1")
    while IFS= read -r link; do
        target=$(readlink "$link")
        linkdir=$(dirname "$link")
        if [ "${target#/}" != "$target" ]; then
            abs=$(realpath -m "$target")
        else
            abs=$(realpath -m "$linkdir/$target")
        fi
        ln -sfn "$(realpath -m --relative-to="$linkdir" "$abs")" "$link"
    done < <(find "$root" -type l)

РЕШЕНИЕ:
    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <dir>" >&2; exit 1; }
    [ -d "$1" ] || { echo "$1 не е директория" >&2; exit 2; }
    root=$(realpath "$1")
    while IFS= read -r link; do
        target=$(readlink "$link")
        linkdir=$(dirname "$link")
        if [ "${target#/}" != "$target" ]; then
            abs=$(realpath -m "$target")
        else
            abs=$(realpath -m "$linkdir/$target")
        fi
        case "$abs" in
            "$root"/*|"$root") ;;                    # вътре — пропускаме
            *)
                if [ -e "$abs" ]; then
                    echo "$link -> $abs"
                else
                    echo "$link -> $abs [broken]"
                fi ;;
        esac
    done < <(find "$root" -type l)

ВАРИАЦИЯ В3 — trash.sh: rm, което мести в кошче вместо да трие
------------------------------------------------------------------------
Обектите отиват в ~/.trash/<timestamp>/<пълния им път>; --really вика
истинското /usr/bin/rm.

РЕШЕНИЕ:
    #!/bin/bash
    set -euo pipefail
    if [ "${1:-}" = "--really" ]; then
        shift
        exec /usr/bin/rm "$@"
    fi
    trash="$HOME/.trash/$(date +%s)"
    for arg in "$@"; do
        case "$arg" in -*) continue ;; esac
        if [ ! -e "$arg" ] && [ ! -L "$arg" ]; then     # -L: и счупен линк е обект
            echo "trash: няма такъв обект: $arg" >&2; exit 1
        fi
        abs=$(realpath -s -- "$arg")     # -s: не следвай симлинка (местим самия него)
        dest="${trash}$(dirname "$abs")"
        mkdir -p "$dest"
        mv -- "$arg" "$dest/"
    done

ВАРИАЦИЯ В4 — spy-shell.sh <log> <cmd...>: логващ sandbox [тествано]
------------------------------------------------------------------------
Пуска интерактивен bash, в който изброените команди работят нормално, но
всяко извикване се записва в лога.

РЕШЕНИЕ (генериране на wrapper-и + PATH отпред):
    #!/bin/bash
    set -euo pipefail
    [ "$#" -ge 2 ] || { echo "Usage: $0 <logfile> <cmd1> [cmd2 ...]" >&2; exit 1; }
    log=$(realpath -m "$1"); shift
    touch "$log"
    wrapdir=$(mktemp -d)
    for cmd in "$@"; do
        real=$(command -v "$cmd") || { echo "непозната команда: $cmd" >&2; exit 2; }
        cat > "$wrapdir/$cmd" <<EOF
    #!/bin/bash
    echo "\$(date '+%F %T') $cmd \$*" >> "$log"
    exec "$real" "\$@"
    EOF
        chmod +x "$wrapdir/$cmd"
    done
    PATH="$wrapdir:$PATH" exec bash -i

(в heredoc-а: $log/$cmd/$real се разгъват при ГЕНЕРИРАНЕТО, \$*/\$@/\$(date)
— при ИЗПЪЛНЕНИЕТО на wrapper-а; точно това е смисълът на escape-ването.
EOF редът да е без водещи интервали в реалния файл.)

--- К1. build.sh <Buildfile> <source> — конфиг → генериране на команди ---
Редове: <компилатор> <флагове...> '<абсолютна изходна дир>'; лошите редове
се пропускат; дублирани флагове се чистят.

    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 2 ] || { echo "Usage: $0 <Buildfile> <source>" >&2; exit 1; }
    [ -f "$1" ] || { echo "$1 не е файл" >&2; exit 2; }
    [ -f "$2" ] || { echo "$2 не е файл" >&2; exit 3; }

    name=$(basename "$2" | cut -d'.' -f1)

    while IFS= read -r line; do
        echo "$line" | grep -qE "^[A-Za-z0-9_+-]+( [^' ]+)* '(/[^'/]+)+/?'$" || continue
        compiler=$(echo "$line" | cut -d' ' -f1)
        outdir=$(echo "$line" | rev | cut -d"'" -f2 | rev)
        outdir="${outdir%/}"
        flags=$(echo "$line" | sed -E "s/^[^ ]+ //; s/ *'[^']*'$//" \
                | tr ' ' '\n' | sort -u | tr '\n' ' ')
        echo "${compiler} ${flags}-o '${outdir}/${name}' $2"
    done < "$1"

--- К2. sync.sh <config> — желано срещу реално състояние ---
Конфиг: <услуга> running|stopped, # коментари; реалност: ./svcctl list
(редове: име pid|- състояние); разлика → отпечатай start/stop команда;
лош ред / непозната услуга → предупреждение, продължаваме.

    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <config>" >&2; exit 1; }
    [ -f "$1" ] || { echo "$1 не е файл" >&2; exit 2; }

    actual=$(./svcctl list)                    # ВЕДНЪЖ, не в цикъла

    while IFS= read -r line; do
        [ -z "$line" ] && continue
        if ! echo "$line" | grep -qE "^[a-z][a-z0-9_-]* (running|stopped)$"; then
            echo "предупреждение: невалиден ред: $line" >&2
            continue
        fi
        name=$(echo "$line" | cut -d' ' -f1)
        want=$(echo "$line" | cut -d' ' -f2)
        if ! echo "$actual" | cut -d' ' -f1 | grep -qx "$name"; then
            echo "предупреждение: непозната услуга: $name" >&2
            continue
        fi
        state=$(echo "$actual" | grep "^${name} " | cut -d' ' -f3)
        if [ "$want" != "$state" ]; then
            [ "$want" = "running" ] && echo "./svcctl start $name" \
                                    || echo "./svcctl stop $name"
        fi
    done < <(sed -E 's/#.*$//; s/[[:space:]]+$//' "$1")

--- К3. dedup.sh <dir> — дупликати по съдържание + hard links ---
Еднакво съдържание (sha1sum) → замени дупликатите с hard link към първия;
вече линкнатите (еднакъв inode) не са дупликати; отчети групи + байтове.

    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <dir>" >&2; exit 1; }
    [ -d "$1" ] || { echo "$1 не е директория" >&2; exit 2; }

    index=$(mktemp)
    while IFS= read -r rec; do                 # rec = inode@size@path
        path=$(echo "$rec" | cut -d'@' -f3-)
        hash=$(sha1sum "$path" | cut -d' ' -f1)
        echo "${hash}@${rec}"
    done < <(find "$1" -type f -printf "%i@%s@%p\n") > "$index"

    groups=0; saved=0
    for hash in $(cut -d'@' -f1 "$index" | sort | uniq -d); do
        recs=$(grep "^${hash}@" "$index")
        distinct=$(echo "$recs" | cut -d'@' -f2 | sort -nu | wc -l)
        [ "$distinct" -le 1 ] && continue      # само hard links помежду си
        groups=$((groups + 1))
        keeper=$(echo "$recs" | head -n1)
        kInode=$(echo "$keeper" | cut -d'@' -f2)
        kPath=$(echo "$keeper" | cut -d'@' -f4-)
        size=$(echo "$keeper" | cut -d'@' -f3)
        while IFS= read -r rec; do
            [ "$(echo "$rec" | cut -d'@' -f2)" = "$kInode" ] && continue
            path=$(echo "$rec" | cut -d'@' -f4-)
            rm "$path" && ln "$kPath" "$path"
            saved=$((saved + size))
        done < <(echo "$recs" | tail -n+2)
    done
    rm "$index"
    echo "групи с дупликати: $groups; спестени байтове: $saved"

Клопка: find | while през pipe губи saved/groups (subshell) — затова
навсякъде done < <(...).

--- К4. memcop.sh <лимит MB> — ps счетоводство + условен kill ---

    #!/bin/bash
    set -euo pipefail
    [ "$(id -u)" -eq 0 ] || { echo "изисква root" >&2; exit 1; }
    [ "$#" -eq 1 ] || { echo "Usage: $0 <лимит MB>" >&2; exit 2; }
    echo "$1" | grep -Eq "^(0|[1-9][0-9]*)$" || { echo "невалидно число" >&2; exit 3; }

    limitKB=$(( $1 * 1024 ))
    for user in $(ps -eo user= | sort -u); do
        total=0
        while IFS= read -r rss; do
            total=$((total + rss))
        done < <(ps -u "$user" -o rss= 2>/dev/null)
        if [ "$total" -gt "$limitKB" ]; then
            pid=$(ps -u "$user" -o pid=,rss= | sort -n -k2 | tail -n1 \
                  | tr -s ' ' | cut -d' ' -f1)
            echo "$user ${total}KB — kill $pid"
            # реално: kill "$pid"; sleep 2; kill -KILL "$pid" 2>/dev/null
        fi
    done

--- К5. bake.sh <цел> — мини-make (2024-SE-04): рекурсия + -nt ---
bakefile: редове цел:зависимости:команда.

    #!/bin/bash
    set -euo pipefail
    [ "$#" -eq 1 ] || { echo "Usage: $0 <target>" >&2; exit 1; }
    [ -f ./bakefile ] || { echo "няма bakefile" >&2; exit 2; }

    bake() {
        local target="$1"
        if ! grep -qE "^${target}:" ./bakefile; then
            [ -e "$target" ] && return 0       # обикновен файл — готов е
            echo "непозната цел: $target" >&2; exit 3
        fi
        local rule deps cmd dep rebuild
        rule=$(grep -E "^${target}:" ./bakefile | head -n1)
        deps=$(echo "$rule" | cut -d':' -f2)
        cmd=$(echo "$rule" | cut -d':' -f3-)
        rebuild=0
        [ -e "$target" ] || rebuild=1
        for dep in $deps; do
            bake "$dep"
            [ "$dep" -nt "$target" ] && rebuild=1
        done
        [ "$rebuild" -eq 1 ] && echo "$cmd"    # реално: eval "$cmd"
        return 0
    }
    bake "$1"

МИНИ-РЕЧНИК НА ИДИОМИТЕ (наизуст)
------------------------------------------------------------------------
екстремум:       sort -n -t'X' -kN,N | head -n1 (мин) / tail -n1 (макс)
ключ отпред:     find -printf "КЛЮЧ@ПЪТ\n" | sort -n | tail -1 | cut -d'@' -f2-
                 (%s размер %n links %T@ mtime %i inode %d дълбочина %u owner)
два паса:        grep "$( ...сметни ключа... )" файл | ...
честоти:         sort | uniq -c | tr -s ' ' | sort -n -k1 | tail -1 (мода)
без вод. нули:   ([1-9][0-9]*|0)
последно поле:   rev | cut -d'X' -f1 | rev
пази променливи: done < <(команда)   вместо   команда | while
релативен път:   realpath -m --relative-to="ОТКЪДЕ" "ЦЕЛ"
замяна на линк:  ln -sfn НОВО ЛИНК   (без -n влиза ВЪТРЕ в директория-цел)
засенчи команда: PATH="моята_дир:$PATH"; export PATH; exec bash -i
env + команда:   exec env K1=V1 K2=V2 команда арг...  (търси с новия PATH)
