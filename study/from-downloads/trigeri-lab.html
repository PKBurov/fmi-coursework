Изследване на тригери и броячи

Цифрова схемотехника · попълване на таблиците от упражнението

Колона „тетрадка“ е това, което е записано в тетрадката; колона Qt+1 е за листа. В табл.3, 4 и 5 записаното в тетрадката е систематично обърнато спрямо работата на тригера (Set → 0, Reset → 1) – най-вероятно е отчитан индикаторът на Q (DI1), а не на Q (DI0). Разликите са маркирани с ⚠.

1. Асинхронен RS тригер – характеристични уравнения (Табл.1а)

За схемата с ЛЕ ИЛИ-НЕ (изходите един през друг):

Qt+1RS = R ∨ Qt  =  S ∨ R·Qt   (R·S = 0)
Qt+1RS = S ∨ Qt  =  R ∨ S·Qt   (R·S = 0)

R·S = 0 е условието да не се подава забранената комбинация R = S = 1 (ред 0* в Табл.1а). Проверка: S=1 → Q=1; R=1 → Q=0; R=S=0 → Qt+1 = Qt (запазване).

Без импулс (C = 0) входните И-НЕ са запушени → тригерът запазва състоянието при всякакви R, S.

При C = 1 работи като RS тригер: S = 1 → Set (1), R = 1 → Reset (0).

R = S = 1 при C = 1 е забранено: и двата изхода стават 1 (Q = Q = 1), а след края на импулса състоянието е неопределено – затова „1*“, както в Табл.1б. В тетрадката е записано „Qt* – забранено“; важното е звездичката и думата „забранено“.

3. Синхронен по ниво D тригер – фиг.4, Табл.3

CDQt+1тетрадка
0 (---)0QtQt
1QtQt
001 ⚠
110 ⚠
Qt+1D = D
Qt+1RS → Qt+1D :  D = S = R

Т.е. S = D и R = D. Заместено: Qt+1 = D ∨ D·Qt = D, и R·S = D·D = 0 – забранената комбинация изчезва. Това е и защо долният И-НЕ на фиг.4 взима сигнала от изхода на горния (там е D).

4. D тригер по фронт, ИС 7474 – фиг.6, Табл.4

SRCDQt+1тетрадка
11↑000
↑110 ⚠
01XX10 ⚠
1001 ⚠
001*Qt*

Редовете в тетрадката са леко разместени – прочетени са по реда на листа.

При S = R = 1 тригерът записва D само при нарастващ фронт на C (↑): Qt+1 = D.

S (PRE) и R (CLR) са асинхронни, активни с ниско ниво: S = 0 → Q = 1, R = 0 → Q = 0, без значение C и D (затова X).

Приоритет: асинхронните входове S, R имат по-висок приоритет от синхронния вход D – докато някой от тях е 0, D и C не влияят. S = R = 0 е забранено (Q = Q = 1) → 1*.

5. Асинхронен брояч с Kбр = 4 – фиг.7 (времедиаграми)

Двата тригера са включени като T-тригери (D ← Q), затова всеки сменя състоянието си при нарастващ фронт на своя C. Q1 се сменя на всеки фронт ↑ на ТГ (честота f/2); C на втория тригер е от Q1 (45 → 53), затова Q2 се сменя при всеки фронт ↑ на Q1 (честота f/4). Началното състояние е прието 00. Числата отдолу са Q2Q1: 0 → 3 → 2 → 1 → 0 – 4 различни състояния, т.е. Kбр = 4 (при тази връзка броячът брои назад). Малкото изместване на фронтовете на Q1 и Q2 показва закъснението tз на всеки тригер. tз01 и tз10 не са в снимките.

6. Master-Slave JK тригер, ИС 7472 – фиг.8, Табл.5

SRCJ1K1Qt+1тетрадка
1100Qt1 (поправено)
0101 ⚠
1010 ⚠
11Qt1
01XXX10 ⚠
1001 ⚠
001*Qt*

J2 = J3 = 1; K2 = K3 = 1, така че J = J1, K = K1.

J = K = 0 → запазва (Qt); J = 0, K = 1 → Reset (0); J = 1, K = 0 → Set (1); J = K = 1 → превключва (Qt) на всеки импулс.

Сравнение с RS: JK работи като RS (J ≡ S, K ≡ R), но комбинацията J = K = 1 не е забранена – вместо неопределено състояние тригерът се превключва. Асинхронните S, R работят като при 7474.

Изходният импулс при MS: при C = 1 входните данни се записват в Master, а Slave е блокиран; при спада на C (1 → 0) Master се блокира и състоянието му се пренася в Slave, т.е. изходът Q се сменя по задния фронт на тактовия импулс. Така входовете и изходът никога не са свързани едновременно и няма „състезание“.
