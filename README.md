# FMI Coursework

Coursework and study materials from Sofia University "St. Kliment Ohridski" (Faculty of Mathematics and Informatics, FMI), collected 2019–2024.

## Structure

- **`2019-2020/`** — 1st semester: Algebra, DIS (Differential & Integral Calculus), DSTR (Discrete Structures), UP (Intro to Programming, C++).
- **`2020-2021/`** — 2nd semester: Geometry, OOP, Discrete Mathematics 2, homework scans (`Domashni`).
- **`2021-2022/`** — 3rd semester: SDA (Data Structures & Algorithms), Operations Research (ИО), Game Theory.
- **`2022-2023/`** — `Предмети/` (SEM, DB, DU, SARS, XML courses) plus OS and R scripts.
- **`study/`** — additional study material:
  - `os-course/` — Operating Systems (C/shell exam solutions and data).
  - `fmi-courses/` — course notes (.md/.txt) and code extracted from FMI Moodle course pages.
  - `leetcode/`, `from-downloads/` — practice problems and notes.

## Notes

- Large binary/media files (videos, images, archives) and build artifacts (`.git`, `node_modules`, `bin/`, `obj/`, `dist/`, `target/`, `Debug/`, etc.) are intentionally excluded.
- Commit history is backdated to approximate the real academic timeline (2019–2024).
